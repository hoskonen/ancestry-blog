# Ancestry Dev Blog

This repository contains the development blog for **Ancestry**, a retro-inspired tile-based RPG prototype.

The purpose of this site is to document the ongoing development of the game, including:
- progress updates
- technical experiments
- design decisions
- lessons learned during development

While the main focus is Ancestry, the blog may also include notes and posts about other projects, tools, and ideas explored along the way.

## Tech Stack

- Astro (static site generator)
- TypeScript
- Markdown-based content

## Status

🚧 Work in progress — currently setting up the foundation and content structure.

## Goal

Keep the blog simple, fast, and focused on documenting real development work rather than over-engineering the platform itself.
